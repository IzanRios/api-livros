Nesta atividade será desenvolvida uma aplicação web para gerenciamento de livros, começando pela criação e conexão de um banco de dados MySQL utilizando o XAMPP e o phpMyAdmin. Em seguida, será criada uma API com Python e FastAPI, implementando as operações de cadastrar, listar, atualizar e excluir livros. Por fim, será desenvolvido um Front End com HTML, CSS e JavaScript, que utilizará a API para permitir a interação com os livros diretamente pelo navegador. Durante o projeto, também serão realizados testes e commits no GitHub para registrar a evolução de cada etapa.
